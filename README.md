# IMVU Utility Suite

A modular patching framework for the IMVU desktop client.

Apply only the features you want without waiting for pre-patched client releases.

## Features

- Customizable client enhancements
- Quality-of-life improvements
- Privacy and safety improvements
- Performance optimizations
- Additional utilities as the project grows

---

# Installation

## Step 1 — Open your IMVU Client folder

Press:

```text
Win + R
```

A Run dialog will appear.

Paste:

```text
%AppData%\IMVUClient
```

Press **Enter**.

This will open your IMVU Client directory.

---

## Step 2 — Install the patcher files

1. Open your **Downloads** folder.
2. Open:

```text
imvupatcher.zip
```

3. Drag the **patcher** folder into the IMVUClient directory you opened in Step 1.

Your folder should look like:

```text
IMVUClient
└── patcher
```

---

## Step 3 — First-time setup

Open the `patcher` folder.

Double-click this File:

```text
patch
```

When prompted:

1. Press:

```text
S
```

2. Press:

```text
Enter
```

This installs Python and the required dependencies needed for the patcher to run.

> Note: If it asks "Press Enter to continue" again, press Enter one more time. This is a known issue and will be fixed in a future update.

---

# Step 4 — Patch your client

Before continuing:

⚠️ **Make sure IMVU is completely closed.**

The login screen must also not be open.

Run the patcher again.

You can either:

## Option A — Patch everything

Press:

```text
A
```

Then press:

```text
Enter
```

This applies all available enhancements.

---

## Option B — Select individual features

Choose only the features you want from the menu.

---

# Done!

Your IMVU client is now patched.

Enjoy improvements such as:

- Better chat experience
- Improved user controls
- Quality-of-life enhancements
- Additional client improvements
